# 戀愛行銷與消費者保護 (Love Marketing and Consumer Protection)

本專案為結合 **LLM Wiki 結構化知識庫**、**Agentic Workflow 工作流程圖（Loop/Graph）** 與 **純前端獨立 HTML 互動教學簡報** 之法律科技與法學教育研究成果。

專案聚焦探討：**當業者利用戀愛、曖昧或情感期待招攬消費者，進而誘使其購買高額商品或服務時，這種「戀愛行銷」如何影響消費者的交易決定、侵害消費者權益，以及現行法制（消保法、公平交易法、民法及日本比較法）如何提供救濟與保護。**

## 📖 核心內容架構

### 1. 10 頁教學簡報：甜蜜陷阱・戀愛推銷調查檔案
以「衣渼爾美容案」（公平會公處字第 112094 號）為核心貫穿案例，採四幕情境敘事：
1. **第一幕：心動還是陷阱？**（第 1~2 頁：破題、常見步驟性推銷模式）
2. **第二幕：真實案例拆解**（第 3~6 頁：衣渼爾案處分事實、推銷現場、人際壓力、本票與融資分期風險）
3. **第三幕：法律如何保護你？**（第 7~9 頁：消保法訪問交易 7 日解除權、民法暴利行為要件、日本約會商法借鏡）
4. **第四幕：勇敢自救行動指南**（第 10 頁：存證信函與五步自救 SOP）

### 2. LLM Wiki 知識庫
以 Andrej Karpathy 提出的 LLM Wiki 體系為架構，嚴格遵守「三層不可變／AI 維護」原則與「零虛構（Zero Hallucination）」鐵律：
- **實體要件嚴格檢驗**：明確區分消保法第 19 條之適用範圍（通訊交易、訪問交易），破除「實體營業所簽約免責論」。
- **直溯原始文獻**：所有實體主張均可對照至原始行政處分書、法院判決及學術評析之具體頁碼。
- **客觀並列見解**：中立論述爭點，未經權威實證不輕易武斷宣稱「通說」或「主流」。

### 3. Loop／Graph 自動化與人機協同工作流程
- 設有 **7 個執行節點（Node 1 ~ Node 7）** 與 **7 道檢驗閘門（Gate 1 ~ Gate 7）**。
- 嚴格落實 **「下游鏈式重跑（Cascading Downstream Re-execution）」**：在上游草稿或卡片修正後，下游所有檢核必須順序重跑，確保檔案 100% 同步。
- 設有 **Human-in-the-Loop** 審查機制（Gate 3 大綱人工確認、Gate 7 瀏覽器真實畫面人工驗收）。

## 💻 簡報操作方式

以現代瀏覽器（Google Chrome、Microsoft Edge、Mozilla Firefox 或 Safari）直接開啟 `index.html` 或 `slides/presentation.html`：
- **鍵盤切換**：按下鍵盤 `←` / `→` 或 `Space` 鍵即可前後切換投影片。
- **導航按鈕**：右下角提供「上一頁」、「下一頁」及目前頁碼指示。
- **色彩模式**：點擊右上角 `🌙` / `☀️` 按鈕切換淺色粉嫩模式與深色對比模式。
- **章節目錄**：點擊右上角 `📑` 按鈕可展開抽屜選單，一鍵跳轉至指定投影片。
- **全螢幕模式**：點擊右上角 `⛶` 按鈕可開啟／退出瀏覽器全螢幕展示。
